# Architecture and evaluation protocol

## Article-specific design

The 2025 AIIT paper describes a three-stage convolutional encoder (3-point kernels, 32/64/128 output channels and pooling size 2 at each stage), dropout 0.3, a wavelet-enhanced bidirectional LSTM (156 units), a 312-unit attention layer, sigmoid-based attention activation, Adam training and MSE loss. The Morlet expression in Eq. (8) is `cos(2.1*x)*exp(-x*x/3)`.

The implementation applies the Morlet nonlinearity to outputs of a standard BiLSTM. This is a reproducible architectural interpretation, **not** a claim of equivalence to custom modified LSTM cell gates, which are not fully defined in the paper. Sigmoid attention weights are normalized across time. The exact lookback (16 cycles), learning rate (0.001), batch size (32), training epochs (20), first-observed SOH reference and validation fraction (20%) are implementation choices and are explicitly identified in `configs/paper.json`.

## Training groups

* Group I: model development on B0005/B0006/B0007; B0018 is the held-out test battery (nominal 24 °C group).
* Group II: model development on B0029/B0031/B0032; B0030 is the held-out test battery (nominal 43 °C group).

Targets for the validation interval follow the final 20% of development-cell cycles; historical context is allowed, but no prediction-window input includes its target cycle. Normalization is fitted using development-cell training observations. Test-cell measurements are never used to fit normalization, hidden weights or hyperparameters.

The source archive from NASA includes MATLAB data, while this repository versions derived cycle-level CSV tables. Dataset structure and conversion are not identical to the authors' unavailable experiment scripts; source-feature equivalence remains to be checked against full-resolution traces.

## Scientific reporting

Reference values printed in Table II of the article are not experimental outputs generated by this repository. The table reports for B0018 MAE 0.0028 and RMSE 0.0031, and for B0030 MAE 0.0023 and RMSE 0.0026. New run results must be reported separately. Model variants are provided as ablations, not certified independent replications of each baseline implementation.

The Clean Energy 2025 journal article shares related hybrid concepts, but this repository follows the **AIIT 2025** architecture and the two explicit NASA temperature-group experiments. The publications should not be represented as identical experimental studies.
